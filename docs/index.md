# humanize

Orchestrate, execute, and observe agent flows.

```sh
pip install git+https://github.com/humanfia/humanize2.git
```

## Run a flow

Point humanize at a coding agent CLI you have already logged into, and give it a task.

## Weave a flow

A flow is a directory of Python that drives one or more agents. Whoever writes one is a weaver.

## Work on humanize

Clone it, `uv sync`, and the two gates tell you whether a change is good.
